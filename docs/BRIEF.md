LANGUAGE DETECTION
━━━━━━━━━━━━━━━━━━━━━━

When someone visits:

bassetdaddi.com

automatically determine the most appropriate language.

Priority:

1. Previously selected language stored in cookie
2. Browser Accept-Language
3. English fallback

Logic:

If saved locale exists:
use it.

Otherwise:

If browser language begins with Arabic:
redirect to /ar

Otherwise:
redirect to /en

Do this server-side where possible.

Do NOT rely exclusively on client-side navigator.language.

Avoid:
- visible language flash
- hydration mismatch
- redirect loops

When the visitor manually switches language:

save preference in a cookie.

The manual preference must override browser language during future visits.

Create a minimal language switcher:

EN
عربي

Do not use flags.

When switching language, preserve the current page where possible.

Example:

/en/work → /ar/work

not always back to homepage.
