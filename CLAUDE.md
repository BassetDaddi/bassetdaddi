# bassetdaddi.com

Personal site of Basset Daddi — bilingual (EN/AR, RTL), Next.js App Router, delivered in approval-gated phases.

Before touching anything, read in this order:

1. `docs/BRIEF.md` — the master brief (verbatim, source of truth).
2. `docs/DECISIONS.md` — locked client decisions (identity, logo, links, availability, content integrity).
3. `docs/design-system.md` — tokens, type scales, components, RTL rules, copy.

Rules that are easy to break: no fabricated content of any kind; the accent has a budget; Arabic is authored, never translated; every component is reviewed in both directions; stop at the end of each phase and wait for approval.
